
Medical Website

A modern and responsive Medical Website designed using HTML5 and CSS3. This project provides a clean and professional interface for healthcare services, helping users easily access medical information, doctor details, and healthcare resources.

 Project Overview

The Medical Website is a front-end web project that focuses on delivering a user-friendly healthcare experience. It features a responsive design, attractive layouts, and smooth navigation to ensure accessibility across different devices.

# Features

- Responsive Design for Mobile, Tablet, and Desktop
- Modern and Clean User Interface
- Hero Section with Call-to-Action Buttons
- Healthcare Services Section
- Doctor Information Section
- About Us Section
- Contact Information Section
- Smooth Navigation Bar
- Professional Color Scheme
- Optimized Layout and Typography
- Hover Effects and Interactive Elements

 Technologies Used

- HTML5
- CSS3
- Google Fonts
- Font Awesome Icons
